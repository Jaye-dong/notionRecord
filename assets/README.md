# Assets 目录

此目录用于存放应用的静态资源。

## 需要添加的文件

当你准备发布应用时，需要在此目录添加以下图标和启动画面：

- `icon.png` - 应用图标（1024x1024 px）
- `adaptive-icon.png` - Android 自适应图标（1024x1024 px）
- `splash.png` - 启动画面（1284x2778 px）
- `favicon.png` - Web 版图标（48x48 px）

## 临时使用

在开发阶段，Expo 会使用默认的占位图标，所以你可以暂时不添加这些文件。

## 设计建议

- 使用简洁的设计
- 主色调建议：蓝色（#007AFF）或绿色（#34C759）
- 可以包含记账相关的图标元素（如钱包、账本等）

你可以使用以下工具生成图标：
- [Figma](https://www.figma.com/)
- [Canva](https://www.canva.com/)
- [App Icon Generator](https://www.appicon.co/)
